# nk-puente

Puente Shopify -> Klaviyo: lleva a Klaviyo el telefono de quien abandona el checkout y lo da de alta
en WhatsApp o SMS. Corre en GitHub Actions en cadena, sin depender del programador de GitHub.

Las credenciales van en los secretos del repositorio. Los registros solo muestran cuentas, nunca
emails ni telefonos.
